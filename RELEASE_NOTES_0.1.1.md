# PereHomeLab v0.1.1

Новая версия PereHomeLab с региональными уведомлениями Telegram, назначением ответственных сотрудников и комментариями к вызовам. Существующий мониторинг Home Assistant, регионы, история и заряд батарей сохранены.

## Главное

- Для каждого региона можно подключить своего Telegram-бота, группу и тему.
- Один вызов - одно сообщение: кнопки «🚶 Я иду», «↩️ Отменить», «💬 Добавить комментарий» меняют его состояние без лишних подтверждений.
- После принятия на кнопке виден назначенный сотрудник; другой участник может принять вызов вместо него, если это разрешено настройками региона.
- Принятие синхронизируется с веб-мониторингом и останавливает соответствующий звук. Отмена освобождает вызов без повторного всплывающего окна и звука.
- Добавлены общие профили сотрудников и личный кабинет бота. Корпоративный логин и ФИО вводятся без проверки AD и без одобрения администратора.

## Telegram и сотрудники

- Настройка и проверка бота, привязка темы через `/setup`, тестовая отправка и состояние доставки доступны в отдельной вкладке админки.
- Команда `/setup` действует только в открытом администратором окне; повторные команды не создают поток сообщений и не блокируют принятие вызовов.
- `/start` открывает постоянное меню: посмотреть, заполнить, изменить или очистить корпоративные данные. `/sync` запускает заполнение профиля.
- Пользователи, взаимодействовавшие с ботом, автоматически появляются в разделе «Сотрудники». Доступны поиск, ручное создание, изменение данных, блокировка, ограничения по регионам и журнал изменений.
- Администратор может запретить сотруднику менять и очищать свой профиль в боте. Ограничение действует и для ранее открытых подтверждений.
- Очистка корпоративного профиля не удаляет историю вызовов, Telegram-контакт и административные ограничения.
- Комментарии необязательны: бот запрашивает текст ответом на временное сообщение, сохраняет автора и время, обновляет исходное уведомление. Для удаления ответов пользователей боту нужны соответствующие права в группе.

## Нажатия и история

- В карточках истории под временем отображается «Пошёл»: сначала корпоративный логин, при его отсутствии - Telegram username. Если username отсутствует, используется имя Telegram или ID.
- В деталях видны текущий ответственный, источник принятия и время. Для заполненного профиля отображаются ФИО, корпоративный логин и Telegram; для незаполненного - только Telegram.
- Комментарии отображаются отдельным блоком, без технической истории переназначений. Аудит действий сохраняется в SQLite.
- Добавлены фильтры истории по датам, статусу и тексту, включая поиск по сотруднику и комментарию.
- Время отображается в формате `дд.мм.гггг чч:мм:сс`.
- Исправлено обновление карточек и открытых деталей после назначения, отмены, смены ответственного и восстановления связи.

## Интерфейс и стабильность

- Увеличены детали вызова и комментарии для телевизоров; проверено отображение на узких экранах и при 4K / 300%.
- Исправлен контраст кнопки подтверждения и сохранение громкости. Звук подготавливается автоматически; если браузер запрещает автозапуск, требуется первое взаимодействие со страницей. Kiosk с разрешённым autoplay проверен отдельно.
- Повторные статусы не перерисовывают неизменившиеся карточки. Запросы истории объединяются, состояние вызовов читается пакетно, убраны тяжёлые многоуровневые размытия.
- Добавлена минимальная защита Telegram от спама: отдельные лимиты сообщений и нажатий на сотрудника и бота. Спам одного сотрудника не блокирует остальных.
- Повторный callback не выполняет действие заново; параллельные назначения сохраняют одного текущего ответственного.
- Очередь Telegram и шаги регистрации сохраняются между перезапусками. Исторические события не рассылаются как новые вызовы.
- Сбой бота одного региона не останавливает остальные регионы или Home Assistant.
- Загрузка звука ограничена 20 МиБ, чтобы слишком большой файл не занял всю память процесса.
- Исправлено применение нового пароля главного администратора после изменения env.

## Проверки перед выпуском

- Пройдены 97 автоматических тестов, включая повторы, спам, параллельные назначения, профили и ограничения доступа.
- Пройдены браузерные проверки истории, назначения ответственного, комментариев, защиты от HTML-инъекций, звука, сохранения громкости и адаптивной вёрстки.
- Выполнена проверка основных HTTP-маршрутов работающего сервиса.
- На изолированных контейнерах проверены сохранение БД, загруженного звука, логов и скачиваемого EXE после пересоздания, а также отказ в загрузке слишком большого файла.
- Образ и публикуемые файлы проверены на рабочие секреты. Рабочая БД, логи, звуки и kiosk-бинарники в новую публикацию не включаются.

## Docker

Образы: `bedmah/perehomelab:0.1.1` и `bedmah/perehomelab:latest`.

В отдельной папке развёртывания:

```bash
mkdir -p data logs sound app
docker pull bedmah/perehomelab:0.1.1
docker run -d \
  --name perehomelab \
  --restart unless-stopped \
  -p 80:8000 \
  --env-file secret.env \
  -e HISTORY_DB_PATH=/app/data/press_history.db \
  -e APP_DOWNLOAD_DIR=/download-app \
  --add-host host.docker.internal:host-gateway \
  -v "$(pwd)/data:/app/data" \
  -v "$(pwd)/logs:/app/logs" \
  -v "$(pwd)/sound:/app/sound" \
  -v "$(pwd)/app:/download-app:ro" \
  bedmah/perehomelab:0.1.1
```

## Важно при обновлении с 0.1.0

- Сохраните существующие каталоги `data`, `logs`, `sound`, `app` и сделайте резервную копию БД до обновления. Базу удалять не нужно: новые таблицы и поля создаются автоматически.
- Старые настройки HA продолжают работать. Для Telegram добавьте в env:

```env
TELEGRAM_ENABLED=true
TELEGRAM_ENCRYPTION_KEY=your_generated_fernet_key
TELEGRAM_EVENT_TTL_SECONDS=300
```

- Ключ создайте один раз: `docker run --rm --entrypoint python bedmah/perehomelab:0.1.1 -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"`. Сохраните его в защищённом месте вместе с резервной копией: токены ботов шифруются этим ключом в SQLite. При обновлениях не генерируйте другой ключ.
- Без ключа Telegram не запускается; чтобы временно отключить интеграцию, установите `TELEGRAM_ENABLED=false`.
- Токены отдельных ботов вводятся в админке, а не в образе. Один бот должен обслуживаться одним экземпляром приложения; Uvicorn запускается с одним worker.
- После изменения env пересоздайте контейнер. Для применения обновлённого интерфейса выполните Ctrl+F5, для меню бота отправьте `/start`.
- После обновления проверьте одно физическое нажатие в нужном регионе и принятие вызова в Telegram. Автоматические проверки не заменяют проверку реальной сети, HA и прав бота.
