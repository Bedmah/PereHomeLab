# PereHomeLab v0.1.2

Обновление интерфейса и исправление загрузки истории Home Assistant. Региональные Telegram-боты, профили сотрудников, комментарии и существующие настройки сохранены.

## Главное

- Обновлён внешний вид главной и мониторинга в стиле Liquid Glass: полупрозрачные поверхности, мягкие тени и более спокойные цвета.
- Исправлены ложные нажатия при синхронизации истории: начальное состояние `on` больше не принимается за новое физическое нажатие.
- Переработана сетка истории: высота зависит от содержимого, карточки выравниваются внутри своего ряда, а не растягивают всю страницу.

## Интерфейс

- Счётчики доступных кнопок на главной используют одинаковый размер шрифта, рассчитанный по самому длинному значению. Трёхзначные числа больше не выходят за границы карточек.
- Кнопка скачивания приложения получила заметную реакцию на наведение и нажатие.
- Верхние кнопки мониторинга оформлены в едином стиле; улучшены размеры текста и элементов управления.
- Длинные названия в истории занимают до двух строк. Полное название доступно при наведении и в деталях вызова.
- Дата расположена сразу под названием. Строка «Пошёл» добавляется только при назначении сотрудника.
- Если сотрудник принял один вызов, увеличивается только его ряд. Остальные ряды остаются компактными; карточки не перекрывают соседние.
- Улучшено поведение при сжатии окна, на квадратных и вертикальных экранах. Верхние элементы переносятся при нехватке места.

## История и стабильность

- Первая запись ответа истории HA используется как исходное состояние, а не как событие нажатия. Это устраняет повторное создание вызовов для устройств, которые уже находились в `on` при начале периода или добавлении в HA.
- Последующие реальные переходы состояний продолжают импортироваться с защитой от дублей.
- Ранее записанные ошибочные события автоматически не удаляются: существующая история сохраняется.
- Размытие в мониторинге ограничено всплывающими элементами; прокручиваемые списки не используют тяжёлое многоуровневое размытие.

## Docker

Образы: `bedmah/perehomelab:0.1.2` и `bedmah/perehomelab:latest`.

В папке развёртывания с заполненным `secret.env`:

```bash
mkdir -p data logs sound app
docker pull bedmah/perehomelab:0.1.2
docker run -d \
  --name perehomelab \
  --restart unless-stopped \
  -p 80:8000 \
  --env-file secret.env \
  -e HISTORY_DB_PATH=/app/data/press_history.db \
  -e APP_DOWNLOAD_DIR=/download-app \
  --add-host host.docker.internal:host-gateway \
  -v "$(pwd)/data:/app/data" \
  -v "$(pwd)/logs:/app/logs" \
  -v "$(pwd)/sound:/app/sound" \
  -v "$(pwd)/app:/download-app:ro" \
  bedmah/perehomelab:0.1.2
```

## Важно при обновлении с 0.1.1

- Старый env подходит. Новые обязательные параметры не добавлены. Если задан `APP_VERSION`, измените его на `0.1.2` или уберите, чтобы использовалась версия образа.
- Сохраните каталоги `data`, `logs`, `sound`, `app`, прежний `TELEGRAM_ENCRYPTION_KEY` и сделайте резервную копию перед обновлением. Удалять БД не нужно.
- Остановите и удалите старый контейнер, затем выполните команду запуска с теми же каталогами. Не запускайте два экземпляра с одними Telegram-ботами.
- Каталог `sound` должен оставаться доступным на запись для загрузки через админку. `app` можно подключать только для чтения: EXE размещается в нём с хоста.
- Выполните Ctrl+F5 для загрузки обновлённого интерфейса. Windows kiosk-приложение в этом релизе не пересобиралось.
- После обновления проверьте физическое нажатие и принятие в Telegram. Доставка зависит также от сети, HA и прав бота.
